# Ankit Portfolio

Professional portfolio built with **React + Vite + Tailwind CSS**.

## Setup

1. Install dependencies:
```bash
cd ankit-portfolio
npm install
```

2. Start dev server:
```bash
npm run dev
```

3. Build:
```bash
npm run build
```

## Customize
- Update text/links in `src/components/*.jsx`.
- Replace placeholder image at `public/profile.jpg`.

## Deploy
Use any static host that supports Vite builds (e.g. Netlify/Vercel/GitHub Pages).
